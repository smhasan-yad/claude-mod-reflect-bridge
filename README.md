# claude-mod-reflect-bridge

Spots reusable corrections in short prompts (one small Haiku call, only on correction-like prompts) and saves them on one press to auto-memory, `~/.claude-shared/CLAUDE.md` or `~/.claude-shared/AGENTS.md`. Adapted from claude-reflect by Bayram Annakov (MIT).

## Install

```bash
claude plugin marketplace add smhasan-yad/claude-mod-reflect-bridge
claude plugin install reflect-bridge@claude-mod-reflect-bridge
```

A new chat or /reload-plugins picks it up. Written for the Windows desktop app and terminal (Claude Code mods API); not tested elsewhere.
